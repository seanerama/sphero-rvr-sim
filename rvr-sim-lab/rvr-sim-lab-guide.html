Guide for young coders and their grown-ups

How to use RVR Sim Lab

Practice coding a Sphero RVR+ on the screen first. When your program works in the sim, copy it into Sphero Edu and run it on the real robot.

A tour of the screen

Part 2

Your first program in five steps

  1. Pick Mission 1, Free Roam.It already has a starter program, so you can press Run right away and watch what happens.
  2. Open a category and drag a block.Click Movement on the left side of the Blocks panel. Drag a roll heading 0 ° speed 80 for 1 s block and snap it under the others. Blocks only run if they're connected under when program starts.
  3. Change the numbers.Click a white bubble on a block to type a new number. Try heading 90 to drive right.
  4. Press Run and watch.The orange line shows where the robot drove. Press Stop at any time, or Reset robot to put it back at the start.
  5. Look at the code panel.Every block you add shows up as real code. Flip between JavaScript and Python to see the same program in both languages.
Part 3

One program, three ways to write it

Blocks, JavaScript and Python all tell the robot the same thing. Here's a short program that drives until the color sensor sees red.

when program starts set main LED red ▾ set speed 60 repeat until color sensor sees red ▾
delay 0.05 s
stop 

      

      
Notice the little differences: JavaScript uses setMainLed and curly braces, while Python uses set_main_led, a colon and indentation. In both, await goes in front of commands that take time, like roll, delay and speak.

Part 8

    
Fixing common problems

    

      
My blocks don't do anything when I press Run
Make sure every block is snapped under when program starts. Loose blocks turn gray and don't run.

      
Python says “This line needs a colon”
Lines that start a block, like if, while, for and def, must end with :. The lines under them need 4 spaces of indentation.

      
The robot drives past the red tile
Check the color sensor inside a loop, with a very short delay, and stop right after the loop. A lower speed also helps the robot stop closer to the middle of the tile.

      
I changed the code text, and now my blocks are gone
Your blocks are still saved. When you switch to “Write text”, the blocks pause because they can't read typed code. Press “From blocks” to go back to them. Your typed code is saved too, and it will be there when you come back to “Write text”. Only “Replace with code from blocks” replaces it.

      
Python says something “isn't supported here”
The sim understands the Python most beginners use: variables, if/elif/else, while, for, functions, lists, tuples, dictionaries, slices, f-strings and print. A few advanced features, like classes, list comprehensions and try/except, only work in real Python.

      
Python says I need await, or that I shouldn't use it
Commands that take time, like roll, spin, delay and speak, need await in front, and await only works inside an async def. If you write your own async def go():, call it with await go(). The sim checks this so your program will work on the real robot too.

      
The real robot goes much farther than the sim
Measure your robot with the speed test in Part 6. After that, the sim will drive the same distance.

      
Where did my missions go?
Progress is saved in the web browser you used. A different browser or device starts fresh.
